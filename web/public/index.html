使用用户浏览器的准备步骤
  1. 在终端运行下方对应系统的命令，打开启用本机调试端口的 Chrome。使用单独的用户目录，首次需要在这个窗口中登录；后续使用同一目录会保留登录状态。若已用此目录开过窗口，请先关闭那个窗口再运行命令。
  2. 在该 Chrome 窗口登录商家后台，确认当前店铺。选择上方「优先使用用户浏览器」，端口与命令保持一致，点击「检测用户浏览器」。
  3. 运行「登录与前置准备」检查页面、完成验证码或店铺选择。已有登录时可留空账号密码；完成后点「停止准备」，保留 Chrome 窗口。
  4. 再按需运行创建发货单或装箱发货，建议先快照、测试，再正式执行。脚本在新标签页操作，结束或停止只断开连接，保留用户窗口与页面；运行时请勿同时手动操作任务页面。

Chrome 136 起，调试端口要求非默认用户目录，不能直接接管普通打开的日常 Chrome 窗口。查看 Chrome 官方说明

未开启调试端口、端口不匹配或连接失败时，会自动按原方式启动独立 Chrome，复用项目的共享登录信息；两种方式的登录状态分别保存。回退后若未登录，请先完成登录准备。也可直接选择「原来的独立 Chrome」。

00login-auto读取登录状态

登录与前置准备 ↗

按所选方式打开 Chrome 页面，已有登录可直接继续；也可输入手机号或邮箱和密码自动登录，再手动完成店铺选择。

已保存浏览器登录信息，直接打开页面继续操作；若已失效，请在 Chrome 中重新登录。

账号密码自动缓存在当前浏览器本地，刷新后恢复；点击「清除登录信息」可删除。此脚本会持续运行，直到关闭任务页面或点击「停止准备」。清除登录信息仅清除项目共享配置和控制台缓存；用户浏览器的登录需在其窗口中退出。
