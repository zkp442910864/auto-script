00login-auto读取登录状态

登录与前置准备 ↗

输入手机号或邮箱和密码，脚本自动打开 Chrome 并登录，之后可手动完成店铺选择等前置操作。

已保存浏览器登录信息，直接打开页面继续操作；若已失效，请在 Chrome 中重新登录。

账号密码自动缓存在当前浏览器本地，刷新后恢复；点击「清除登录信息」可删除。此脚本会持续运行，直到手动关闭 Chrome 或点击「停止准备」。
